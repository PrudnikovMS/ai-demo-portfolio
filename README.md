# Портфолио автоматизаций · Максим Прудников

[Открыть интерактивное портфолио](https://prudnikovms.github.io/ai-demo-portfolio/)

Десять интерактивных демо по отчётности, LLM-сценариям, тестированию и видео. У каждого проекта есть вымышленный пример. Его можно изменить, повторить проверку и сохранить таблицу результата в CSV.

| Демо | Что можно проверить |
| --- | --- |
| Сверка отчётов по SKU | Найти дубли, отсутствующие позиции и расхождения в суммах двух выгрузок. |
| ОПиУ по артикулам | Посчитать прибыль и маржу по заданным полям и разобрать случай с нулевой выручкой. |
| Мониторинг позиций | Сравнить позиции товаров по запросам в двух замерах и заметить пропуски. |
| Ответы на отзывы | Подготовить черновики и выделить ответы, которые нужно проверить вручную. |
| Конструктор инструкций для LLM | Собрать инструкцию, ограничения и проверочные сценарии из короткого брифа. |
| Черновик новости для Telegram | Разложить входные факты по полям, заметить пробелы и подготовить текст. |
| Конструктор баг-репорта | Оформить шаги, среду, ожидаемое и фактическое поведение. |
| Проверка CSV перед импортом | Найти пустые поля, дубли и несоответствия схеме до загрузки данных. |
| Проверка субтитров SRT | Проверить нумерацию, интервалы и перекрытия субтитров. |
| Фрагменты для коротких роликов | Выбрать отрывки по расшифровке и получить таймкоды для монтажа. |

## Запуск локально

Из каталога репозитория запустите `python -m http.server 8000` и откройте `http://localhost:8000`. Для проверок выполните `node --test` с актуальной версией Node.js. Установка зависимостей не требуется.

## Границы демо

- Выгрузки читаются в формате CSV или TSV. Для Excel сохраните нужные листы в CSV. Инструкции к конкретной схеме показаны в интерфейсе.
- LLM-сценарии используют локальные правила и проверяемые примеры. API-ключи, платные сервисы и отправка сообщений не используются.
- Подбор фрагментов работает с расшифровкой и таймкодами. Настоящий видеомонтаж происходит в редакторе после отбора.
- Интерфейс и демо работают в браузере. Для публичной витрины использованы вымышленные данные и оригинальные учебные реализации.
